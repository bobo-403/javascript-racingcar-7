# 자동차 경주

주어진 횟수동안 무작위 값에 따라 전진하는 자동차 경주 게임이다.

## 게임 규칙

- 자동차 이름 : `,`로 구분, 5자 이하
- 횟수 : 이동할 라운드 수
- 전진 조건 : 4 이상
- 우승자 : 1명 이상 가능
- 잘못된 값을 입력할 경우 프로그램이 종료된다.

## 프로그램 흐름

1. 경주할 자동차 이름을 입력한다.
2. 시도할 횟수를 입력한다.
3. 입력한 라운드만큼 자동차 전진을 진행한다.
   - 자동차 마다 무작위 값을 뽑는다.
   - 무작위 값이 4이상 이면 전진한다.
   - 한 라운드 진행 후 결과를 출력한다.
4. 우승자를 출력한다.

## 기능 목록

### 입력

- [x] 자동차 이름을 입력한다.
- [x] 시도할 횟수를 입력한다.

### 입력값 검증

- [x] 자동차 이름이 5자 이하인지 확인한다.
- [x] 시도할 횟수가 양의 정수인지 확인한다.

### 게임 준비

- [x] 입력된 자동차 이름으로 게임 자동차 데이터(이름, 위치)를 초기화한다.
- [x] 시도할 횟수로 라운드 수를 초기화한다.

### 게임 진행

- [ ] 입력한 횟수만큼 라운드를 진행한다.
- [x] 한 라운드를 진행한다.
  - [x] 무작위 값을 뽑는다.
  - [x] 자동차를 전진시킨다.

### 우승자 결정

- [ ] 게임 진행 결과를 바탕으로 가장 많이 이동한 자동차 이름을 찾는다.

### 출력

- [x] 한 라운드 진행 결과를 출력한다.
- [ ] 우승자를 출력한다.
